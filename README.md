## How to read this portfolio

Start with a case study for the problem, decisions and evidence. Open its supporting file to inspect the connection between a requirement, a rule and a test. Each case distinguishes completed work from a proposed design or a synthetic example.

The published case studies are intended for professional review. They contain no customer records, employer system exports or simulated commercial sign-offs.
